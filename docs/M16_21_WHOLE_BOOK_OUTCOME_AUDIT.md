# M16.21｜1925年《麻衣相法》268页传统断语词与形貌共现全书审计

## 为什么本轮改用整书OCR统计

之前 M16.9 已完成两份实际原版PDF共 268 页的 PP-OCRv5 形态词扫描，但未单独记录财富、寿命、品德、婚姻、事业、家庭、子嗣、吉凶等传统断语可能出现的位置。M16.18–M16.19 的真实 Qwen3 4B 试验虽然执行了真实模型请求，却持续漏掉「鼻長有壽」对应的传统寿命说法。继续围绕同样三个短句调 Prompt，不能代替全书覆盖。

本轮直接沿用六分片原版PDF OCR 工作流，在不新增用户脸部信息、不修改网站、不发布未核准古籍断语的情况下，给出可审计的原书扫描页索引。

## 本轮产物（真正运行前不宣称完成）

- `scripts/cangjie_outcome_ocr_audit.py`：严格核查原版PDF SHA256、PP-OCRv5 页面元数据和真实OCR文本摘要；按 OCR 行检索十一类以内（当前10类）历史断语词，统计同一OCR行是否另见五官形态词；保留无五官词的历史材料，**不因不能照片识别而丢弃财富、寿命等原典内容**。
- `scripts/cangjie_outcome_ocr_aggregate.py`：对六份分片报告校验完整、唯一、逐页顺序一致的268个页面；输出不同领域词出现的页数、OCR行数、与形态同一行的页数及优先核验页ID，明确未审、未知、不可发布。
- `.github/workflows/cangjie-outcome-268-audit.yml`：真实 6 分片 GitHub Actions，单片包括原版扫描下载、SHA256由代码核对、PaddleOCR CPU真实运行、私有断语词定位。最后的汇总任务必须全部六片成功才执行。
- `tests/test_cangjie_outcome_ocr_audit.py`：阻止将鼻部「年壽」位置名直接视为长寿断语；检验没有面部词也应保存古籍历史词；测试268页漏页、重复页和虚假人工审核。

## 证据标准、误报与缺失

* 所有输入仍是**未完整校勘的古汉语竖排图像OCR候选**。词语“富贵/寿夭/德行”出现本身并不代表其上下文是面相断语：可能是人名、章节标题、词语歧义或OCR错误。
* **同一 OCR 行出现眼、鼻、口等不构成“某种面貌→某种结果”的关系**；竖排断句和OCR拼列、版画/诗诀混排可能造成伪近邻。
* 反之，OCR行未命中词也不能证明原版扫描件没有传统断语：OCR漏字、跨列、异体字、省略说法都会漏检。这是**遗漏与复核索引**，不是全书历史解读完成度。
* 公共GitHub仓库和Artifact仅输出每页类别计数、扫描来源 SHA及页码，不公开未审核原文、整书 OCR 文字、模型补写结果或人脸信息。原始词定位表仅在临时Runner私有目录。
* 此流程**不执行仓颉五路语义提取**。它是为官方仓颉后续批量处理准备按历史领域分层的候选输入索引。官方仓颉仍需要在可控私有工作空间读取完整原典候选段落并保留来源。
* 数据条目必须标为 `source_unverified` 和 `archive_only`；零人工完整页签认、零正式传统命运判定、零新增网站规则。

## 后续要依据实际统计决定什么

先验收 GitHub Actions 全268页的实际完成报告，比较历史断语在十领域的 OCR 词出现页数和同页/同行形态近邻。优先人工校勘原图中明确包含具体外形和传统说法的诗诀，再启动来源受控的仓颉语义提取。这种分工可防止模型跳过原书里真正吸引用户的历史命运、财富及品德内容，同时避免把古人观念变成未经证实的现实预测。
