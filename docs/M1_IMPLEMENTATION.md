# Faceface｜M1 浏览器摄像头与本地几何描述 — 实现记录

日期：2026-11-13。此文件记录实际写入的工程，**不代表已完成真实手机验收**。

## 已写入仓库的可执行代码

- `index.html`, `src/main.tsx`, `src/App.tsx`, `src/style.css`：手机优先相机界面，授权/拒绝、前置相机预览、静帧拍摄、重拍/取消、结果展示、本机下载文本。
- `src/App.tsx`：通过 `@mediapipe/tasks-vision@1.2.3` 的 `FaceLandmarker.createFromOptions` 加载本地推理模型（在浏览器设备端运行，首次须联网下载模型/WASM），对用户拍摄的 `canvas` 执行真正的 `detect(canvas)`。对0人/多人有单独状态。
- `src/descriptors.ts`：五个不同面部区域的纯函数几何观察：整体脸型、眼部、鼻部、口部、下颌；每条保存测量名称、比例和实验性文字描述。没有直接输出个人性格、健康、命运断语。
- `tests/descriptors.test.mjs`：纯几何模拟单测，不能替代真实摄像头/真模型的验收。
- `.github/workflows/ci.yml`：每次 push/PR 执行 npm install、类型检查、构建、模拟几何测试，并保留7天的生产构建产物与依赖锁定文件；PR #1/#2/#3 实际记录已通过。\n- `scripts/browser-model-smoke.mjs` 与 `.github/workflows/browser-model-smoke.yml`：CI 在 Chromium 将 Google 官方人像样例喂给模拟摄像头，**真实初始化 MediaPipe/提取关键点/生成五区域形态描述**；PR #3 测试成功，测试图仅临时下载，不纳入仓库。

## 浏览器启动方式

```bash
npm install
npm run dev
```

浏览器打开控制台显示的本地地址。真实手机需要**HTTPS**（仅电脑 localhost 可享受安全上下文特例），不能用未经 HTTPS 配置的局域网 HTTP 地址直接判断摄像头失效。

生产构建：`npm run build`；几何模拟测试：`npm test`。**目前不提供可用的公开部署地址**。

## 网络、隐私和版权边界

- 相机静帧只画在页面内存 Canvas，不使用 `fetch` / `XHR` / 业务 API 发送照片，不调用 localStorage/IndexedDB 保存结果；用户主动保存时才创建文本 Blob。
- 依赖和 WASM 从 npm/CDN 装载；模型暂从 Google Cloud Storage 下载，首次联网必需。网络服务商可看到网络请求元数据，MediaPipe SDK 的性能/使用指标披露仍需核实。**尚未完成真机网络抓包审计，不能宣称已证明零外传。**
- 模型版本、使用许可、可用性及静态资源自托管方案仍需后续核查；上线前考虑锁定资源和供应链。不能因为“模型在浏览器运行”就认定第三方脚本完全无数据风险。
- 形态分类阈值全部为**探索性占位值**，没有真实样本标定或跨设备测试；现阶段只能作为技术管线是否输出可读文本的验证，不是准确的脸型分类器。
- 本次**没有接入古籍判词**：此前规则尚未迁入并完成逐条原页核验，因此不能编造出处。M2 需要将有据规则与描述 ID 连接并形成简洁/详细双报告。
