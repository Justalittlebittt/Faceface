## 当前开发优先级（2026-11-13已调整）

- **阶段一：真实核心闭环（当前唯一开发优先级）**：创建可运行的国际网页，完成真实前置摄像头、本地模型、跨区域形态语义、少量有出处规则匹配、双版报告及用户主动保存；至少在 Android Chrome 和 iOS Safari 真机实测。仅完成模拟样例不算通过。
- **阶段二：广度扩充**：依据真实识别效果逐步扩展全脸特征、已核验的古籍规则和报告内容，不让眉毛占据研究主线。
- **阶段三：产品完善及上线**：移动端体验、隐私证据、合规检查、免费公开测试网址；有真实流量后再单独评估广告与中国大陆收款手续。
- **并行知识库线**：1925年《麻衣相法》五卷逐页完整归档与校勘的目标不变；仅将已核验的可调用规则逐批接入，**不以全书完成作为首版网站上线前置条件**。

**注意：此节是新执行顺序，不代表任何代码/真机/上线任务已经完成。** 详细验收见 [ROADMAP.md](ROADMAP.md)。

## 不能混淆的五种“完成”

1. 设计完成：文档/字段清晰。
2. 文献核查：给得出版本、卷次、原始页。
3. 模拟完成：假设结构化数据通过匹配逻辑。
4. 真实设备通过：真相机、真模型、真日志与可复核输出。
5. 发布通过：国际网站可用、隐私及运营条件有证明。

**截至2026-11-13，项目以第1-3类成果为主，没有第5类成果。**
