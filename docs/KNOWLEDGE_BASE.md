# Faceface｜《麻衣相法》全书库与视觉语义匹配

## 目标：全部收录 ≠ 全部自动判断

正式版必须以选定底本为准，**完整记录《麻衣相法》的全部原书说法**，包括五官、三停、五岳、十二宫、五行形貌、相色气、形神、骨相、诗诀、图谱、综合断语及非面部的全身相关内容。即使用户的一张正脸无法观察，也要保存在原典库中。

这与“能够根据实时照片启用多少条解读”是两个不同指标。严禁为了触发更多古籍内容而捏造不可见特征。

## 固定版本与来源

当前主底本：1925年文明书局秦慎安校勘《麻衣相法》五卷。初期研究使用两个数字化扫描文件；原扫描文件编号、PDF页码与正文卷次不等价。必须保留：
- 作品、底本、出版信息、扫描原件文件名/来源；
- 正文卷、篇、印页、扫描页、段落/图谱；
- 原文转录、必要条件、例外、出处校核状态；
- 其它版本异文单独存放，不合并覆盖原文。

对扫描件和文本是否有权复制到公开GitHub需要另行核查；没有充分依据前不要上传整部扫描或可能受保护的全文。

## 采用“两层知识库”

### A. 全量原典档案层

无损地登记所有篇章、图谱、形态词、断语、相互矛盾的记载和非照片可判断内容；不因“无法自动使用”而删除。对卷次、页码、漏页、异文和OCR歧义逐一标记。

### B. 经过校验的可调用规则层

把能由视觉语言表达的传统形态转为具有完整条件的候选规则，并标记：
- 文字直接符合 / 仅部分相似 / 条件不足；
- 来源已核验 / 待校验 / 存在冲突；
- 是否适合进入简洁报告、详细文化引用或仅做历史归档；
- 与生活建议的关联是否**现代创作**，不要声称古籍原文即是建议。

古籍里涉及财富、寿命、品德等话语可以作为历史文化原文记录，但不能仅凭外貌对真实用户下事实结论。

## 仓颉 Skill：使用正确的部分

已查阅：https://github.com/kangarooking/cangjie-skill

其 v2.5.0 核心是书籍方法论转可执行Agent技能；它不是把整书所有文本无损落库的自动程序。此前已按其方法进行少量真实古籍原页的人工辅助试点，但尚未使用官方CLI编译出完整Skill，不存在“全书已经蒸馏”的事实。

本项目只借鉴整书梳理、多角度提取、来源核查、审计和能力卡思想；**先逐页完整保存原文，再提取/筛选可执行规则**。仓颉过滤掉的历史断语必须留在原典库，而不是被删除。

## 视觉描述与古籍匹配

V2.5首版候选词典47项覆盖9区：
- 整体轮廓6、额头4、眼睛7、鼻部7、口部5、下颌6、面颊4、耳部5、眉部3。
- 描述如“偏长、较圆、口角略上扬、鼻尖偏圆”。眉毛修饰、妆容、光线、姿态的外在因素影响必须考虑。
- 可见性不足则 unknown；不能直接把现代“鼻尖偏圆”当成古籍完整“鼻准丰隆”的条件已满足。

V2.7局部25项古文短语中8项候选映射，V2.8扩展35项历史词中19项候选映射；数据可能重叠，尚无全书去重和实际真人识别的证据。

### 每条规则需要的核心信息

| 字段 | 要求 |
| --- | --- |
| ID | 稳定唯一标识，保留修订历史 |
| 版本来源 | 作者/底本/卷/章/扫描文件和页码/印页 |
| 历史原文 | 有可查引用，区分转录与白话释义 |
| 观察条件 | 对应形态的全部必要条件、可选条件及组合关系 |
| 视觉字段 | 与47项词典的标准特征ID映射，明确完整/部分相似 |
| 观察限制 | 遮挡、妆容、表情、侧面要求及照片不可见因素 |
| 历史断语 | 原书相关传统说法，不能冒充现实事实 |
| 内容适用 | 仅史料 / 详细参考 / 有边界的简洁文化启发 |
| 生活建议 | 由现代产品编写并审核，独立于古籍引文 |
| 校验状态 | 已对照原页、待校验、有异文、冲突等 |

## 完整性硬指标

- 选定底本扫描页覆盖率 **100%**；每页有记录/缺损说明。
- 篇章覆盖率 **100%**；不以候选规则数量代替原文覆盖。
- 全部能够识别的独立历史断语都有原文位置与必要条件，冲突/重复可复查。
- 自动报告规则覆盖率单独计算，并且只有满足识别与来源要求才启用。
- 不得把“提取了35个图谱词”称为“完整收录35条可用性格结论”。

## 当前可执行研究次序

先建立扫描底本目录和原文台账，再将仓颉提取流程批量用于全部相关段落，统一词汇并填充规则条件，双向更新视觉特征词典。与国际网站摄像头/本地推理验证并行推进。
