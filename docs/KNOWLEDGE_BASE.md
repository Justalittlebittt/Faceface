# Faceface｜《麻衣相法》全书库与视觉语义匹配

## 目标：全部收录 ≠ 全部自动判断

正式版必须以选定底本为准，**完整记录《麻衣相法》的全部原书说法**，包括五官、三停、五岳、十二宫、五行形貌、相色气、形神、骨相、诗诀、图谱、综合断语及非面部的全身相关内容。即使用户的一张正脸无法观察，也要保存在原典库中。

这与“能够根据实时照片启用多少条解读”是两个不同指标。严禁为了触发更多古籍内容而捏造不可见特征。

## 固定版本与来源

当前主底本：1925年文明书局秦慎安校勘《麻衣相法》五卷。初期研究使用两个数字化扫描文件；原扫描文件编号、PDF页码与正文卷次不等价。必须保留：
- 作品、底本、出版信息、扫描原件文件名/来源；
- 正文卷、篇、印页、扫描页、段落/图谱；
- 原文转录、必要条件、例外、出处校核状态；
- 其它版本异文单独存放，不合并覆盖原文。

对扫描件和文本是否有权复制到公开GitHub需要另行核查；没有充分依据前不要上传整部扫描或可能受保护的全文。

## 采用“两层知识库”

### A. 全量原典档案层

无损地登记所有篇章、图谱、形态词、断语、相互矛盾的记载和非照片可判断内容；不因“无法自动使用”而删除。对卷次、页码、漏页、异文和OCR歧义逐一标记。

### B. 经过校验的可调用规则层

把能由视觉语言表达的传统形态转为具有完整条件的候选规则，并标记：
- 文字直接符合 / 仅部分相似 / 条件不足；
- 来源已核验 / 待校验 / 存在冲突；
- 是否适合进入简洁报告、详细文化引用或仅做历史归档；
- 与生活建议的关联是否**现代创作**，不要声称古籍原文即是建议。

古籍里涉及财富、寿命、品德等话语可以作为历史文化原文记录，但不能仅凭外貌对真实用户下事实结论。

## 完整性硬指标

- 选定底本扫描页覆盖率 **100%**；每页有记录/缺损说明。
- 篇章覆盖率 **100%**；不以候选规则数量代替原文覆盖。
- 全部能够识别的独立历史断语都有原文位置与必要条件，冲突/重复可复查。
- 自动报告规则覆盖率单独计算，并且只有满足识别与来源要求才启用。
- 不得把“提取了35个图谱词”称为“完整收录35条可用性格结论”。

## 传统断语完整保留合同（2026-11-19补充）

**产品目标修订：历史相术中的财富、寿命、品德、性情、婚姻、事业、家运、子嗣、吉凶、社会地位等，是原典知识库的重要内容，而不是应在仓颉阶段被过滤的无用文本。** 即使网站首版暂不展示或照片无法判断，也必须原样记录其来源、上下文、历史含义和解释关系。用户最关注的可能正是这类古人“相貌—命运／性情”关联；产品可以准确介绍传统信念，但绝不因此将其说成科学事实。

### 不丢信息的三层结构

1. **原典层（长期完整保存）：** 保留原文、图谱、部位和形态描述、条件／例外／复合条件、对应的财富／寿夭／德行等历史断语、矛盾记载、版本异文、卷章及印页／PDF页定位。没有照片可观测性也不能删除；只标记 `photo_observability=unavailable`。未校勘内容必须是 `source_unverified`。
2. **仓颉关联候选层（可批量挖掘）：** 从一段原典中分别抽取 `observable_morphology`、`historical_claim`、`source_condition`、`exception`、`context`，并通过稳定 `source_passage_id` + `relation_id` 记录彼此关联；历史断语必须保留原文与归属，不能被概括为现代事实，不因没有对应视觉字段而拒绝归档。上游官方五类提取器只是辅助工具，Faceface 的“形态—断语”关系需要专门的结构化归档，不能让方法论提取器丢失叙事内容。
3. **网站展示层（独立发布决策）：** 历史资料收藏／原典浏览可以比照片报告容纳更广泛的内容；实时照片报告只在形态可观察、原文可信、必要条件可满足、展示话术经过审核时关联历史信念。写“《麻衣相法》在某篇中将某类鼻形与富贵联系起来（传统观点）”，不能写“你一定有钱、短寿、不诚实”等事实判断。尤其寿命／健康、道德品格类不作为个体判断或评分。

### 候选关系最低字段

`source_passage_id`、`edition_id`、`source_pdf_sha256`、`pdf_page_zero_based`、`printed_volume`、`section`、`quote_original`、`transcription_review_status`、`facial_region`、`morphology_original`、`conditions_original`、`exception_original`、`historical_claim_original`、`historical_claim_domain[]`、`traditional_relation_type`、`photo_observability`、`report_eligibility`、`conflicting_sources[]`、`modern_explanation`（必须标为现代解释，非古籍引文）。不清楚的字段明确为 `unknown`，不得补写臆造值。

### 提取与覆盖审计的实际约束

- **双覆盖率：** 逐页原典归档覆盖率，以及历史断语及其形态关联保留率；不允许仅报告有照片可用的规则数。任何不进入照片报告的断语仍须在史料层有明确去向。
- **先忠实保存再解释：** 原文提到财富、寿夭或品行，不得在自动蒸馏时因价值判断而悄悄删除、改写为积极心理建议或只保留五官外形。
- **版本与事实边界：** 古人的判断是古籍所载的传统观念，不代表现代科学成立；涉及针对真人的负面道德标签、寿命、疾病及财务结果，不能通过面貌生成断言。
- **研发阶段**：这一补充当前是知识库和仓颉提取的合同，不宣称真实整书抽取已完成，也不立即改变网站现有十张来源卡和报告内容。
