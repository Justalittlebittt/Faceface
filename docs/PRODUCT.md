# Faceface｜国际网站产品规格 v1

## 核心定位

面向国际用户、免费、手机优先的传统面相文化体验网站。用户通过浏览器实时摄像头采集可见面部形态，系统把全脸转换成标准自然语言，再匹配《麻衣相法》与《易传·说卦》的传统知识，给出简洁版与详细版报告。用户得到的应当是：传统相法中的解释、现实生活中可反思的情境、具体改善建议。

传统相术属于历史文化观点，不能当作经科学证实的人格、道德、健康或命运检测。生活建议是现代编写的反思内容，不得冒充古籍原话。

## 用户流程（正式要求）

1. **首页**：介绍服务与文化娱乐性质，无强制账号或个人资料收集，点击 Start Reading。
2. **实时拍摄**：用户主动授权前置摄像头；正脸引导框、光照/位置提示，拍摄不从相册上传作为主流程；无需音频权限。
3. **缺失耳部补拍**：只有耳廓确实无法观察而且耳相需要时，才引导拨开头发、按需补拍左/右一侧；可跳过，自拍镜像与实际左右分开。
4. **确认**：可重拍、取消；无需回答任何“性格是否符合”的问题。
5. **全脸描述**：面部整体、额头、眼、鼻、口、下颌、面颊、耳、眉九个区域；眉部只占少量字段，考虑化妆、修眉、表情、遮挡；描述粗粒度即可，但不可猜不可见处。
6. **古籍关联**：标准描述词匹配古籍条件，有直接、部分相似、不足三种状态，不能凭一个相似词强行命中完整相型。
7. **默认简洁报告**：简短面相观察、古籍传统解释、生活情境、具体建议；不大段展示古文。
8. **免费详细报告**：展示更多五官与全脸特征、传统解读、八卦取象、原文版本与卷页、局限条件；两版共享同一份分析事实。
9. **自主保存/离开**：用户主动导出报告；网站不默认上传、不长期保存面部照片、面部特征或报告，退出后尽量释放内存并停止相机。

## 报告写作合同

### 简洁版示例（仅为文案结构，不是真实人脸诊断）

- 可见形态：例如眼型偏细长、下颌较宽等。
- 传统解读：明确“按照某些传统相法的说法”而非宣称测出了真实的性格。
- 生活表现：将历史意象转化为一个具体、用户可自行反思的情境；不捏造其真实经历。
- 建议：给出1–2项可执行行为，例如重要决定前比较两种方案的利弊，而非泛泛“多思考”。
- 简短文化性质说明：不重复堆砌免责声明。

### 详细版

- 清晰列出观察依据、不可见/被遮挡字段、妆容/表情/角度干扰。
- 《麻衣相法》版本、卷次、章节、扫描页或书页以及具体条件；《易传·说卦》有据的八卦取象。
- 将原书历史断语与现代编写的建议分开，不能把传统性情与现实人格画等号。
- 同一条规则的简洁/详细解释不能前后矛盾。
- 未满足完整条件的候选，最多标记为部分相似的文化参考。

## 语言与视觉

定位国际用户：**英文优先是当前建议，中文保留**，实际首发市场和优先语言尚需确认。古籍原文保留中文，并提供经过核校的英文释义，避免把意译标为原文直译。移动端优先，兼容桌面；现代克制、偏东方编辑风格，Refero仅作为设计参考。

## 不做的功能

不做独立《周易》起卦、夫妻相、时间轴照片对比、默认云端历史记录、额外性格验证问卷、将外貌转为人格/道德评分、云端大模型收取用户照片、需要用户上传本地相册照片才可使用的主流程。

## 验收关键

- 真实手机能独立完成拍摄、必要补拍或跳过、获取两种报告、保存、退出。
- 多张不同脸实际输出跨区域不同的可观察描述；同一输入与相同版本应稳定。
- 生成报告要有古籍来源和明确关联条件；缺失信息不能随机补齐。
- 不把文化趣味判断表述为医学、心理测量、职业适配、财富寿命的事实。
- 完整古籍库的全部收录目标独立于首测少量视觉字段。
