# Faceface｜决策与待决事项（2026-11-13）

## 用户已经确定的合同

| ID | 决策 | 说明 |
| --- | --- | --- |
| D01 | **从微信小程序改为国际网站** | 旧微信接口/平台审核不再是工程基础；应采用标准移动/桌面浏览器 |
| D02 | **实时摄像头拍照** | 不以用户本地相册上传作为主流程；双耳按需侧脸补拍，可跳过 |
| D03 | **整张脸转为标准自然语言** | 面型、额、眼、鼻、口、下颌、面颊、耳及少量眉；不再聚焦眉毛/眉骨 |
| D04 | **《麻衣相法》为主、八卦取象为辅** | 不单独起卦，不创造“眼大火旺”等缺乏文献依据的公式 |
| D05 | **简洁版默认、详细版免费展开** | 简洁版突出传统性情意象、生活场景和可操作建议；详细版溯源 |
| D06 | **无性格确认问卷** | 用户拍摄后直接看报告，不问“是否符合” |
| D07 | **不上传、不留存面部照片/特征** | 设备端处理优先，用户自行保存；需要技术证据；广告数据另外处理 |
| D08 | **正式版完整记录《麻衣相法》所有说法** | 小规模测试规则只是测试子集，不是最终规则上限 |
| D09 | **仓颉辅助蒸馏，不替代完整原典库** | 收录全部历史断语与“允许报告触发的条目”分开管理 |
| D10 | **允许形态粗略对应** | 但不可把不可见部位编造出来，也不可将局部近似称作古籍完整判断 |
| D11 | **尊重历史相术边界** | 不声称凭照片科学测出用户性格、品德、疾病、财富或寿命 |
| D12 | **原产品免费，广告只是商业化候选** | 广告不插入拍摄过程，国际网站广告政策尚需验证 |
| D13 | **先核心真实验证，再扩大内容广度** | 首先验收真人拍照→本地多区域形态描述→有出处的规则匹配→双版报告→自主保存；首轮少量跨区域字段只是技术验证，不降低正式版覆盖目标 |
| D14 | **全书整理并行，不阻塞首版网站** | 1925年《麻衣相法》完整归档和校勘目标不变；只有已核验规则参与自动报告；首发不以整书完成为前提 |
| D15 | **广告及个人收款办理推迟至有流量后** | 首版先免费公开上线验证真实使用；广告平台申请、中国大陆个人银行收款具体办理及相关税务准备延后，基础上线合规与隐私审查不能延后 |

## 仍未确认，不得擅自写成事实

- **首发国家与语言**：英文优先为合理建议，中文原典/报告保留；全球发布还是先选国家尚未敲定。
- **Web 框架**：React + TypeScript + Vite 的轻量静态方案是建议，尚未验收。
- **浏览器本地视觉模型**：尚未选定通过真实iOS/Android验证的模型和权重版本。
- **域名和部署服务商**：未选择、未购买、未部署。
- **具体广告商及同意管理**：未开通、未验证收益，适用法律待对应市场审查。
- **详细报告导出**：图片、PDF或两者均提供待性能/体验测试。
- **扫描件公开许可与全书转录质量**：尚需核查，不可未经授权将扫描件直接公开。

## 明确停止的旧方向

不再继续以微信小程序作为主产品；不因微信审核纠结而阻塞国际网页研究；不反复深挖少数眉形代替全脸语言；不把若干候选图谱称作全书蒸馏；不把478关键点或逻辑单测通过宣称“真机面相分析已成功”。

**版本纪律**：每项实质性变更更新此文件及STATUS/ROADMAP；保留历史决策的解释，避免无意义重复约定。
