# Faceface｜总体实施规划与里程碑

> **当前状态是产品设计与研究交接，尚未恢复代码开发。** 本计划给出执行顺序和可检验的放行条件，不承诺虚构的完成日期。

## 核心路线

**两条工作线并行：** A. 真实国际网站最小闭环；B. 《麻衣相法》完整知识库。两者在规则匹配/报告阶段汇合。不要先花大量时间整理几条眉毛规则，也不要等全书蒸馏完才验证真实浏览器推理。

### M0｜仓库及历史成果交接

- [x] GitHub 仓库创建，国际网站目标与旧微信路线区分。
- [x] 核心项目文档建立。
- [ ] 将 V2.5 的47字段词典、V2.6技术分层、V2.7/V2.8古籍映射和旧代码原型审查后**择优迁入**，每项附真实版本、来源和“模拟/未验收”标签。
- [ ] 建立原始古籍扫描件/转录来源的授权及版本清单。

**Gate M0**：仓库内没有未标注出处的规则、没有被当成生产可用的旧 Python/微信工程。

### M1｜国际浏览器端的真实摄像头与模型验证（最高优先）

- [ ] 用 HTTPS/localhost 的浏览器摄像头获得正脸图像，允许重拍和拒绝授权。
- [ ] 选择可在浏览器设备端运行的人脸关键点/轻量图像模型；确认许可、加载大小、移动设备内存。
- [ ] 至少用 Android Chrome 与 iOS Safari 真机验证摄像头、停止释放、模型运行。
- [ ] 从多个区域生成实际标准语言，而不仅输出478坐标：例如脸型、眼型、鼻翼、口角、下颌。
- [ ] 完成真机隐私网络审计：照片、坐标、面部语义及个人报告没有出站请求。
- [ ] 手机低光、遮挡、妆容、不同表情、角度做失败路径验证。

**Gate M1**：具有真实浏览器模型输出、设备测试和隐私证据，不接受纸面模拟替代。

### M2｜古籍匹配与双版报告最小闭环

- [ ] 将全脸观察字段统一ID与枚举，支持 unknown / visibility / confounders。
- [ ] 每条古籍规则给出卷页、必要条件、组合条件、例外、来源等级。
- [ ] 采用“完整符合/部分相似/不足”的明确匹配状态，不以向量语义近似直接判命。
- [ ] 用同一份规则匹配结果生成英文优先的简洁/详细报告；现代建议独立归档。
- [ ] 对不同实拍观察测试差异化内容、同输入稳定性和双版一致性。

**Gate M2**：真照片 → 语言描述 → 可回查的古籍候选 → 两份不矛盾的报告，一条可复核链路。

### M3｜完整原典库建设（与 M1/M2 同步推进）

- [ ] 合规取得所选1925年《麻衣相法》五卷原件、逐页索引、扫描页与正文卷次对应表。
- [ ] 按原书目录及逐页文本建立全文、图谱、观察条件、历史断语、例外条件档案。
- [ ] 仓颉辅助多角度批量提取、来源核查和去重；不能以它的 Skill 晋级结果代替全部原文归档。
- [ ] 标注不可拍摄的形神、全身/骨相、品德或寿夭等条目：**记录完整但不直接给真人下判断**。
- [ ] 完成原书篇章/页面100%覆盖审计和缺损/异文清单。

**Gate M3**：全底本有追溯完整性报告，自动启用规则数量另行统计，不夸大为“全书规则都能识脸”。

### M4｜产品完成度与国际化

- [ ] 移动优先页面：引导、拍照、按需耳部补拍、确认、分析、简洁报告、详细报告、保存。
- [ ] 英文界面与报告、中文古籍核校及切换，必要时多语言与可访问性。
- [ ] 处理无脸、多人、拒绝权限、浏览器不支持、弱网、无耳部数据等情况。
- [ ] 不使用默认上传照片、不需要登录、不增加性格问答。
- [ ] 评估报告导出为图片或PDF，用户保存前不做持久化。

**Gate M4**：普通用户可从首页独立完成全部流程，低端手机表现、说明与建议可阅读。

### M5｜国际网站上线和商业化

- [ ] 域名、HTTPS、静态托管/CDN、依赖与模型授权审查、回滚及安全检查。
- [ ] 明确首发地区，检查相关隐私、儿童、消费保护与内容宣传法律要求。
- [ ] 如启用广告，核查广告平台规则、适用地区同意机制、广告脚本与脸数据隔离；不在摄像头页展示广告。
- [ ] 提供真实的隐私条款、网络与存储证据，不宣传“我们绝不处理任何个人信息”。
- [ ] 正式访问、手机兼容性、错误监控、推广素材与基础流量实验。

**Gate M5**：网站可访问、可回滚，国际合规/安全证据与真实用户旅程具备，不把广告上线或收益写成既成事实。

## 减法原则

不再循环只产出少量模拟眉相报告；不为每种古籍相形单独做视觉模型；不在单个小功能上反复叠加复杂防御性代码；不混淆完成设计、文献校验、模拟通过、真机通过和已上线。

## 下一项真正要执行的工作

**先创建国际网站的浏览器相机+本地模型验证切片，使用V2.5词典的跨区域候选字段输出自然语言。** 与此同时启动可追溯的原典页目录、仓颉批量抽取计划。只有证据合格，才扩大视觉词数和报告规则规模。
