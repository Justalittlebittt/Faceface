# Faceface｜国际网站隐私、法律和商业化审计

## 隐私承诺的准确边界

**产品目标**：用户在自己的浏览器设备端完成拍摄、面部特征提取、古籍规则匹配、报告生成；Faceface 不建立面部信息上传接口，不保存原始照片或生物识别特征，报告由用户自行保存。

这是一项**尚未通过正式代码和网络审计的设计承诺**，不能在上线前虚称已得到技术证明。

“面部照片不上传、不存储”也不等于“网站完全不处理任何个人信息”：托管/CDN访问日志可能记录IP等数据；国际广告或分析服务可能处理 cookie、设备信息或其它数据，必须单独披露和核实。

## 国际Web实施要求

| 项目 | 必须做到 | 未来证据 |
| --- | --- | --- |
| 摄像头 | HTTPS安全环境中由用户点击后请求视频权限，不请求麦克风 | 浏览器权限和代码审计 |
| 视频/静帧 | 仅浏览器内存中处理，不出站 | 手机浏览器HAR/抓包/禁止上传测试 |
| 478关键点或其他特征 | 不上传到服务器、广告SDK或分析服务 | 数据流审计、网络负载核查 |
| 个人化报告 | 默认不在服务端/浏览器永久存储，用户主动保存 | localStorage、IndexedDB、Cache、后台日志扫描 |
| 退出 | 关闭摄像头tracks，释放不再需要的内存 | 真实浏览器流程测试 |
| 模型/规则 | 可以经CDN下载静态资源，但请求中不携带人脸资料 | 第三方资源与域名清单 |
| 广告 | 摄像头页不加载追踪广告；广告只在适当结果页面展示 | SDK清单、请求审计、用户同意管理 |
| 用户身份 | 不强制注册、手机号或账号 | 流程验收 |

## 地区合规核查

本项目已从微信转国际网站，后续需要按实际首发国家/地区判断法律，不再把微信小程序审核当作国际网站的发布门槛。

- **Web摄像头**：浏览器 getUserMedia 通常需要 HTTPS 安全上下文和用户授权（localhost 可用于开发）。官方参考：https://developer.mozilla.org/en-US/docs/Web/API/MediaDevices/getUserMedia
- **欧洲隐私**：GDPR对个人信息处理有要求；为了唯一识别自然人而使用的生物识别数据属于特殊类别，但不是每张普通人脸照片自动落入该特殊类别。仍需逐项评估此产品的照片及设备数据处理。官方参考：https://commission.europa.eu/law/law-topic/data-protection/information-individuals_en
- **英国相似边界**：英国 ICO 解释了专门生物识别数据与普通照片的区分，不能据此免除其他隐私义务。参考：https://ico.org.uk/for-organisations/uk-gdpr-guidance-and-resources/lawful-basis/special-category-data/what-is-special-category-data/
- **广告合规**：Google AdSense在EEA/英国/瑞士等地区有消费者同意及CMP要求。未来选择广告服务商后再按最新政策配置；不允许用“没有面部数据库”绕过广告隐私要求。参考：https://support.google.com/adsense/answer/13554020?hl=en
- **其它地区与未成年人**：根据首发地区额外评估消费者保护、儿童/青少年、宣传真实性及广告政策，不提前声称已完成全球合规。

## 传统文化内容的风险

《麻衣相法》中含历史性格、财富、姻缘、寿命、品德等断语。允许作为合法引文与传统思想资料研究，不等于能够从外貌科学地判定用户的性格、道德、健康、职业能力或一生未来。英语文案尤其应当明确文化性质，不能以此做招聘筛选、健康建议、种族/族裔推测或歧视性排序。

八卦取象用于文化解释，不新增独立起卦，也不凭尺寸自造五行能量分数。所有现代处世建议应可执行、非诊断性，且不能捏造用户实际遭遇。

## 上线前必须形成的隐私证据包

1. 部署版本、依赖与模型许可清单、实际托管服务商及第三方脚本列表。
2. Chrome Android / Safari iOS 的真实摄像头、拒绝权限、终止相机及本地识别测试记录。
3. 浏览器/抓包网络证据，证明脸帧、图片、坐标、语义描述、报告不向任何服务端上传。
4. 本地存储与服务器日志排查：无照片、脸部坐标、个性化画像数据。
5. 广告和分析脚本隔离检查、需要的地区同意机制及隐私告知。
6. HTTPS、安全响应头、依赖漏洞与数据泄漏处置审查。
7. 明确哪些法律判断仍需专业审核、哪些陈述只属于设计目标。

**不要用“已承诺”替代“已证明”，也不要把网站托管和广告流量的信息收集混在“不收集面部数据”的承诺里。**
